# 종부세 계산기 개발 프롬프트 (Claude Code에게 그대로 붙여넣어 사용)

아래 내용을 통째로 복사해서 Claude Code(또는 Claude)에게 전달하면 됩니다.

---

## 프롬프트 시작

기존 사이트(머니깨비, compressdeck.com)에 "종합부동산세 계산기"를 새로 추가해줘.
기존 계산기(청약 가점 계산기, 신용점수 시뮬레이터 등)와 **동일한 UI/UX 톤**을 유지하고,
회원가입 없이 브라우저 안에서만 계산되는 클라이언트 사이드 계산기로 만들어줘.
(입력값은 서버로 전송하지 않는다는 기존 사이트 정책 유지)

### 1. 입력 필드 (사용자가 넣는 값)

- **공시가격** (숫자 입력, 원 단위. 억 단위로 보기 좋게 콤마 처리)
- **실거주 여부** (실거주 1주택 / 비거주 1주택 / 다주택 — 3개 중 선택)
- **주택 수** (1채 / 2채 이상 — 다주택 선택 시에만 노출)
- **부부 공동명의 여부** (단독명의 / 공동명의 — 선택 시 계산 방식 분기)
- **연령** (숫자 입력, 60세 이상부터 고령자 세액공제 적용 대상이므로 필요)
- **보유기간** (연 단위 숫자 입력, 5년 이상부터 장기보유 세액공제 적용)
- 위 세 항목(공동명의, 연령, 보유기간)은 "고령자·장기보유 세액공제 계산해보기" 라는
  접이식(collapsible) 섹션 안에 넣어서, 기본 계산은 간단하게 하고 원하는 사람만 펼쳐서
  세부 계산하도록 UX 구성해줘.

### 2. 계산 로직 (2026년 8월 발표 세제개편안 기준)

**기본공제 (2026년 기준, 기준선 넘어야 종부세 대상)**
```
실거주 1주택자: 14억 원
비거주 1주택자: 9억 원
다주택자: 4억 원 (+ 거주주택 비중에 따라 최대 5억 원 추가 가능 — 이 부분은
  복잡하니 1차 버전에서는 "다주택자 기본 공제 4억 원"으로 단순화하고,
  주석으로 "거주 비중에 따른 추가공제는 세무 전문가 확인 필요"라고 표시)
```

**과세표준 계산식**
```
과세표준 = (공시가격 합계 − 기본공제) × 공정시장가액비율
```

**공정시장가액비율 (2026년 기준, 향후 단계적 인상 예정이므로 연도 선택 옵션도 고려)**
```
실거주 1주택: 60% (2027년 70%로 인상 예정)
비거주 1주택 / 다주택 일반: 60% (2027년 70%, 2028년 80%로 단계적 인상 예정)
```
→ 가능하면 "적용 연도" 선택 드롭다운(2026 / 2027 / 2028)을 추가해서
  향후 몇 년간 세부담이 어떻게 변하는지도 보여주면 콘텐츠 가치가 커짐.

**세율표 (누진세율, 2028년 최종 적용 기준 — 주택 수 무관 단일세율로 개편 예정)**

| 과세표준 구간 | 세율 | 누진공제 (참고용, 실제 계산은 구간별 합산으로) |
|---|---|---|
| 3억 원 이하 | 0.5% | 0원 |
| 3억 초과 ~ 6억 이하 | 0.7% | 60만원 |
| 6억 초과 ~ 12억 이하 | 1.3% | 420만원 |
| 12억 초과 ~ 25억 이하 | 2.0% | 1,260만원 |
| 25억 초과 ~ 50억 이하 | 3.0% | 3,760만원 |
| 50억 초과 ~ 94억 이하 | 4.0% | 8,760만원 |
| 94억 원 초과 | 5.0% | 1억 8,760만원 |

계산 방식은 반드시 **누진세율(구간별 나눠서 합산)** 방식으로 구현할 것.
예: 과세표준이 4.2억이면 "3억×0.5% + 1.2억×0.7%"로 계산 (전체 금액에 최고구간 세율을
단순 곱하지 않도록 주의 — 이게 제일 흔한 계산 실수 포인트).
누진공제표를 같이 넣으면 검증하기 쉬움: 과세표준 × 세율 − 누진공제 = 산출세액.

**세액공제 (고령자·장기보유, 실거주 1주택자만 해당 — 접이식 섹션에서 계산)**

고령자 공제:
```
60세 이상 65세 미만: 20%
65세 이상 70세 미만: 30%
70세 이상: 40%
```

장기보유 공제:
```
5년 이상 10년 미만: 20%
10년 이상 15년 미만: 40%
15년 이상: 50%
```

- 고령자 공제 + 장기보유 공제 **합산 공제한도는 최대 80%**로 제한해야 함.
- 이 공제는 **1세대 1주택 실거주자에게만** 적용됨을 화면에 명확히 안내.

**세부담 상한 (안내 문구로만 처리, 계산 로직에 복잡하게 넣지 않아도 됨)**
- 전년도 대비 세부담이 일정 비율(1주택자 150%, 다주택자 300% 등, 정확한 수치는
  최신 시행령 확인 필요) 이상 급증하지 않도록 상한이 있다는 점을 안내 문구로만 표시.

### 3. 출력 (결과 화면)

```
예상 종부세액: OOO만 원

[계산 과정 펼쳐보기]
1) 과세표준: (공시가격 - 기본공제) × 공정시장가액비율 = OOO원
2) 해당 구간: OO% 세율 구간
3) 산출세액: OOO원
4) 세액공제 적용 후 (해당 시): OOO원
```

기존 사이트의 "연말정산 환급액 계산기"처럼, 결과 아래에
**"핵심 공제 구조만 반영한 간이 추정치이며 실제 세액과 다를 수 있습니다.
정확한 금액은 국세청 홈택스 또는 세무사 상담을 통해 확인하세요"**
같은 면책 문구를 동일한 톤으로 넣어줘.

### 4. FAQ 섹션 (기존 사이트 FAQ 패턴과 동일하게 4~5개 추가)

- 종부세 계산기는 어떻게 세금을 계산하나요?
- 재산세랑 종부세는 뭐가 다른가요? (기존 사이트에 재산세 계산기 없다면 간단 설명만)
- 공시가격은 어디서 확인하나요? (부동산공시가격알리미 안내)
- 다주택자 계산 결과가 실제와 다를 수 있는 이유는?
- 이 계산기 결과가 실제 고지서 금액과 같은가요? (→ 아니요, 간이 추정치)

### 5. 관련 아티클 (계산기와 같이 노출하면 좋은 콘텐츠, 별도 작업 요청)

- "종부세, 재산세랑 뭐가 다른 거지?"
- "누진세율이 뭐길래? — 소득세도 종부세도 다 이 방식이에요"
- "실거주 1주택자 vs 비거주 1주택자, 세금이 왜 이렇게 다를까"
- "60세 넘으면 종부세가 왜 더 크게 오를까 — 고령자 공제 이해하기"

### 6. 데이터 최신성 주의사항 (구현 시 반드시 반영)

- 이 스펙은 **2026년 8월 3일 발표된 세제개편안** 기준이며, 세율·공제는
  **2026년부터 2028년까지 단계적으로 시행**되는 내용임.
- 국회 통과 전 발표 단계의 내용이 포함되어 있을 수 있으므로, 계산기 하단에
  "2026년 8월 발표된 세제개편안 기준이며, 국회 통과 과정에서 세부 내용이
  변경될 수 있습니다"라는 안내 문구를 반드시 넣을 것.
- 정기적으로(예: 분기별) 국세청·기획재정부 발표 확인 후 세율표 업데이트 필요.
